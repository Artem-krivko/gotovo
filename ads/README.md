# Контекстная реклама gotovo

Эта папка — единый рабочий контур для Яндекс Директа и Google Ads. Здесь
хранятся бизнес-решения, планы измерения, черновики кампаний, журналы изменений
и код безопасной работы с API.

## Текущий этап

1. Подготовить измерение и хранение источника заявки.
2. Создать отдельные OAuth-приложения и получить API-доступы.
3. Проверить доступы только операциями чтения.
4. Подготовить кампании в режиме dry-run.
5. Любое создание или изменение объектов в рекламных кабинетах — только после
   отдельного явного подтверждения владельца.
6. Запуск показов и расход бюджета — отдельный финальный гейт.

## Структура

- `business-context.md` — подтверждённые бизнес-параметры и KPI.
- `access-setup.md` — безопасная настройка доступов и список переменных.
- `measurement-plan.md` — события, источники и модель атрибуции.
- `yandex-direct/` — материалы только по Яндекс Директу.
- `google-ads/` — материалы только по Google Ads.
- `logs/` — журнал будущих действий в кабинетах.
- `env.example` — шаблон переменных без секретов.
- `audit-2026-09-01.md` — технический аудит измерения и pre-launch гейты.
- `market-research-2026-09-01.md` — рынок, конкуренты и правила платформ.
- `campaign-plan-v1.md` — раздельная стратегия Яндекса и Google без запуска.
- `yandex-direct/dry-run-v1.json` и `google-ads/dry-run-v1.json` — точные
  черновики будущих операций; `apply=false`, расход не разрешён.

Яндекс и Google не объединяются в одну кампанию, один набор конверсий или один
отчёт об эффективности.
