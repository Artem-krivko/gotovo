# Google Ads

Google Ads оценивается и настраивается после базовой готовности Яндекс Директа.
Здесь будут отдельные семантика, конверсии, UTM, объявления и бюджет. Данные
Google не используются как замена Метрике или атрибуции Яндекс Директа.

Техническая документация для заявки Google Ads API Basic Access генерируется
скриптом `build_api_tool_design.py` в `output/pdf/google-ads-api-tool-design.pdf`.
