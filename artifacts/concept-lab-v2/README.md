# Concept Lab v2 — concepts

Пять независимых AI-концептов для витрины готовых сайтов.

- `dentist-editorial.webp` — спокойная сервисная редакционность: вертикальная навигация, документальная фотография и care-path вместо карточек услуг.
- `tattoo-artbook.webp` — асимметричный art-book/contact-sheet: работы и процесс вместо промо-блока и каталога услуг.
- `coffee-magazine.webp` — журнальная композиция о месте: фотоэссе, вертикальный индекс и бумажный callout вместо ecommerce-сетки.
- `gym-motion-system.webp` — динамичный тренировочный журнал: документальная съёмка движения, контрастная типографика и training track вместо шаблонного оффера фитнес-клуба.
- `legal-dossier.webp` — спокойное юридическое досье: индекс материалов, документы и редакционные пометки вместо корпоративных клише.

Общие ограничения генерации: без вымышленных брендов, телефонов, адресов,
цен, скидок, таймеров, отзывов, статистики, гарантий и рейтингов. Все пять
направления созданы как high-fidelity desktop UI mockups в формате 4:3.

Первые три концепта подключены к витрине. `gym-motion-system.webp` и
`legal-dossier.webp` предназначены только для согласования и пока не подключены.
